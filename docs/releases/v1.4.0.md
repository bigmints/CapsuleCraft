# CapsuleCraft v1.4.0 — planning, hierarchy, email import

**2026-10-22** · [All releases](https://github.com/kostyk348/CapsuleCraft/releases) · [Changelog](../../CHANGELOG.md)

The "workspace that doesn't lie" release.

| | |
|---|---|
| 📋 **Planning layer** | Tasks across the whole vault: month grid, overdue / today / week buckets, priorities, ICS (VTODO) export. Due dates and priorities live inside the `.eml` TODO blocks |
| 🔎 **Task filters** | One filter bar across Agenda, Kanban and Gantt: text, status, priority, due bucket, capsule and tag. Counts, stats, calendar dots and ICS export follow the visible set; quick-add clears filters so a new task is never silently hidden |
| 🗂 **Kanban + `/task`** | To do / In progress / Done board with drag-and-drop, per-card status, and `/task` converts the paragraph you are typing into a trackable task |
| 📈 **Gantt timeline** | Day-scale chart with start/due bars, a today marker, dependency arrows and blocked-task warnings. Cycles are rejected before an edge is added — no fake progress |
| 🌲 **Hierarchical pages** | Nest pages as a wiki tree — parent stored in `X-Capsule-Page-Parent`, breadcrumbs, cycle-safe reparenting, orphan promotion, and amber hierarchy edges in the graph. Page tree and mail threads stay separate |
| 📨 **External email import** | Drop a real Gmail / Outlook / Thunderbird `.eml` into the vault: MIME, quoted-printable, RFC 2047 headers and CID images are decoded into blocks, with an **Original Email ↔ Capsule Dashboard** preview switch |
| ⌨️ **Command palette + history** | `Ctrl/Cmd+K` searches every action; undo/redo keeps capsule edits recoverable |
| 🌍 **RU / EN** | Interface localization with a persistent toggle — Russian default, English translation (some block-level labels still pending) |
| 🎙️ **Real audio only** | A new voice note starts microphone capture immediately; if the mic is unavailable it offers a file picker. Fake waveforms, fake timers and the `SIMULATED` badge are gone |
| 🧹 **No demo content** | Fresh installs start truly empty — the sample vault, its loader and every demo string are removed |
