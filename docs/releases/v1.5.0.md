# CapsuleCraft v1.5.0 — the rename and the native shell

**2026-10-23** · [All releases](https://github.com/kostyk348/CapsuleCraft/releases) · [Changelog](../../CHANGELOG.md)

The release where CapsuleOS becomes **CapsuleCraft** — and gains a second,
webview-free shell over the same `.eml` folder.

## Name and identity

- New name in the app title, README (EN/RU), docs, workflows and every
  user-facing string, with a mascot and a matching icon set: Windows `.ico`
  (16–256), macOS `.icns`, Linux PNGs, Microsoft store tiles and the web favicon.
  The native shell draws the mascot in its title bar and as the taskbar icon.
- **Compatibility kept on purpose**: the `.eml` format, `X-Capsule-*` headers, the
  `@capsuleos.local` Message-ID domain, the `com.capsuleos.app` data folder, crate
  names and browser storage keys are unchanged. Every vault written by CapsuleOS
  opens as-is.

## Native egui shell (`native/`)

A separate binary over the same folder, with no browser engine:

| | |
|---|---|
| 🔗 **`[[Wiki links]]`** | Parses links from page text, paints them in the accent colour, lists **Links** and **Linked from**, navigates on click and creates a missing page from its title |
| ✏️ **Renames keep the wiki alive** | Changing a page title rewrites every `[[old title]]` in the vault (imported emails are never touched) and reports how many links moved |
| 🔍 **BM25 search** | Ranks whole-page text, shows the relevance score and a sentence excerpt with the matched words highlighted |
| 👀 **Folder watching** | Reloads when an `.eml` changes on disk — debounced, skipped while edits are unsaved, own writes ignored |
| 📥 **Drop to import** | Dropped `.eml` files are copied into the vault byte-for-byte, with a dimmed drop hint and a skipped-file count |
| ✅ **Planning** | Agenda, Kanban, Gantt and calendar over every task in the vault, quick add, ICS export |
| 🕸 **Graph, threads, MIME, email** | Labelled relationship graph, reply chains from `In-Reply-To`, raw MIME and imported-mail previews |
| 📸 **`--snapshot`** | Renders the real window to PNG (`--view`, `--page`, `--search`, `--scroll`, `--locale`, `--frames`), so README screenshots come from the app |

Threads view fixes: cycles are walked once, orphan replies stay visible, replies
render under their root, and a Threads / All pages switch shows real counts.

## Web app

The web shell keeps its 1.4 feature set; the rename is the substantive change.
`npm run build` and the 151-test vitest suite pass, and the native crate adds 69
cargo tests of its own.

## Known gaps

Audio playback and code execution are not implemented in the native shell — see
[LIMITATIONS.md](../../LIMITATIONS.md#native-egui-prototype).
