# CapsuleCraft v1.6.0 — the native shell ships as a real AppImage

**2026-10-25** · [All releases](https://github.com/kostyk348/CapsuleCraft/releases) · [Changelog](../../CHANGELOG.md)

| | |
|---|---|
| 🖥 **Standalone native AppImage** | `CapsuleCraft_native_1.6.0-x86_64.AppImage` (~8 MB): the egui shell, packaged with linuxdeploy and **zero bundled libraries**. Depends only on `libc`/`libm`/`libgcc_s` (glibc ≥ 2.17) and an X11 or Wayland desktop — no WebKitGTK, no WebView2, nothing to install |
| 🤝 **Related by meaning** | Pages ranked by tf-idf cosine similarity over the BM25 index |
| 🖱 **Hierarchy drag & drop** | Move pages around the tree with the mouse |
| 🧪 **97 native tests** | The egui suite grew from 69 to 97 unit tests |

The old Tauri/web AppImage stays published for parity, but from this release the
**native** artifact is the recommended one on Linux: it is smaller, starts faster
and has no browser engine inside at all.

## Verify

```bash
sha256sum -c SHA256SUMS.txt
./CapsuleCraft_native_1.6.0-x86_64.AppImage          # opens the default vault
./CapsuleCraft_native_1.6.0-x86_64.AppImage /path/to/your/.eml/vault
```
