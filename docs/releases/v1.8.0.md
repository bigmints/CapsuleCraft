# CapsuleCraft v1.8.0 — Two-tier header, Zen mode, macOS builds

Released 2026-10-26.

## Highlights

- **New native header** (PR #12 by kobaltGIT): a brand bar over a section tab
  strip — Page, Planning, Graph, Threads, MIME, Email — with Standard and Zen
  layouts, a wide canvas mode, and UI state that survives a restart.
- **macOS arm64**: `CapsuleCraft_native_1.8.0_arm64.app.zip` — the same egui
  shell as a `.app` bundle (ad-hoc signed), plus the legacy Tauri `.dmg`.
- **AppImage is catalog-grade**: built on Ubuntu 22.04, self-contained
  (glibc 2.35), bundles the dlopen'ed X11/xkbcommon/wayland libraries, and
  carries AppStream metadata. AppImageHub: *Test passed*.

## Fixes

- IMAP modal: buttons no longer spill outside the panel; the sync actions and
  the dialog actions live on separate rows.
- AppImage: fixed broken symlinks in `usr/lib` that made `xkbcommon-dl` panic
  (`Library libxkbcommon-x11.so could not be loaded`), and added a CI guard
  against broken symlinks in the AppDir.
